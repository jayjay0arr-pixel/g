How to write formulas

Paste everything in one go. One formula per line, parts separated by ; (or a tab):

name ; formula ; accepted units ; unit shown ; symbol units

Formula: use {top|bottom} for fractions, √{…} for roots, ² ³ for powers, × for multiply.

Symbol units: σ@Pa,MPa|F@N|A@m². Each symbol, then @, then the units accepted for it (the first is shown as the answer). Symbols are separated by |. Leave a symbol out and its unit isn’t asked. Everything after the formula is optional. You can also paste lines in the built-in array style ["name","formula","units","shown","symbol units"],.

Show example
Normal stress ; σ = {F|A} ; pa,n/m2,mpa ; Pa (N/m²) ; σ@Pa,MPa|F@N|A@m²
Kinetic energy ; KE = {1|2} × m × v² ; j,joule ; J (joule) ; KE@J|m@kg|v@m/s
